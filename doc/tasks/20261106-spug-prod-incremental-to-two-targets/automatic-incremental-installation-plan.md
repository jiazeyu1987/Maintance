## 经验门禁
- Trigger：更新已运行控制或新增备份周期配置。Preflight check：实际服务 PID/原配置 pin/程序清单、当前无活动操作与持同一来源锁、原业务状态和共享挂载、存储余量、最终源码提交及干净新构建工作区。
- Blocker：原59恢复未完成时不得更新其控制；并发源工作、输入漂移、旧点或原件不完整、构建/测试失败、真实计划接口失败均阻止相应安装或提交。
- Verification：实际新进程导入及配置、HTTP计划、源身份与日志、原服务/挂载/历史保持，随后真实 Spug 登录和连续自动增量父链证明。
- Forbidden action：不重启整机或整个 Docker，不修改主程序/业务数据库/旧归档，不删除公司共享盘或旧失败；不得将本地单元测试记成真实备份成功。
- Evidence：本子计划、execution-log、最终实现提交、release-build-<commit>.json、逐服安装回执、实际 UI 原编号及原生结果。
