- Blocker：无法确认远端已启用时只陈述已验证事实；建议不构成安装授权。
- Verification：本地入口检索、既有设计说明和正式服核查结果支持同一建议；必要技术语义以官方资料为准。
- Forbidden action：不更改产品代码、远端配置、业务数据或运行服务；不重复正式服故障注入。
- Evidence：execution-log.md、前序 runtime-readonly-evidence.json 以及文档检索结果。
