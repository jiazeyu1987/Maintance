## 预期验证
发布未验收、失败、恢复待处理或有并发争用时不得清理；成功验收后可清理已失效旧载荷。当前版本/恢复点、在用演练、业务数据、历史和凭据保持。清理结果和失败原因可见，不伪装发布失败或吞掉清理失败。逐普通文件身份复核，禁止递归删除、跟随链接、全局Docker prune或NAS写入。本次测试使用临时目录、实际清理函数及受控执行器依赖，真实三服无发布/删除操作。
