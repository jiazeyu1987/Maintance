## 经验门禁
- Trigger：发布收尾自动删除旧包/恢复载荷及执行器变更。
- Preflight check：读取经验索引命中的发布/恢复、安全清理、多机器接管和worktree规则；核对当前代码入口及所有生成路径，保护既有脏改动；删除按精确普通文件白名单和文件身份复核执行。
- Blocker：当前版本或恢复/演练引用不明、活动任务/锁、路径链接/挂载/跨设备/NAS、不可分离并发修改、测试失败时，对应删除必须停止并暴露原因。
- Verification：BDD先定义，RED→GREEN→REGRESSION，真实临时文件验证unlink与保护集合；核对触发时机、失败状态、幂等和并发门禁；运行配套同步后仅检查健康和代码身份，不发布。
- Forbidden action：不删除业务数据/凭据/历史/NAS，不通过修改摘要或SQLite伪造成功，不自动合并业务项目，不无授权发布三服。
- Evidence：execution-log.md、定向测试结果、代码diff与同步/收尾证据。
