## BDD 场景

- `BDD: 只把稳定项目经验写入长期记忆 -> Given 已有发布后三角色门禁的完整任务证据 / When 执行复盘 / Then 只把能跨任务复用的执行门禁、发布校验和 smoke 约束写入项目记忆。`
