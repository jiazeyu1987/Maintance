# 测试服小程序配置交付

`test58-20261023/` 是从原电脑实际运行的 Spug 配置导出的快照，代码基线为 `ba5fe2f`。仅包含测试服 `172.30.30.58` 的当前安全、快速来源及测试服恢复路由，不包含 IntRuoyi 和正式服、备份服的执行凭据。

## 获取和解密

拉取远端 `int_main`。先核对 `test58-20261023/manifest.json` 中的密文 SHA256。向原电脑持有人单独取得 `test58-config-key.json`，不要把密钥提交到 Git、粘贴到聊天或与密文放在同一个公共位置。

需要 Python 和 `cryptography`；缺少依赖即停止并明确安装该依赖，不切换未加密格式。以下命令在仓库根目录执行，将参数改为接收电脑自己的私密路径；输出目录必须尚不存在：

```powershell
python ops/spug/config-delivery/decrypt.py --package ops/spug/config-delivery/test58-20261023/configuration.aesgcm --key-file C:/SpugPrivate/test58-config-key.json --output C:/SpugPrivate/test58-delivery
```

解密只生成文件，不安装、不启动服务、不提交备份恢复。Windows 输出目录的 ACL 限当前用户及 SYSTEM，其他系统的目录和文件权限分别为 0700、0600。不要将输出目录放在 Git 工作区。

## 内容和安装对应

| 解密目录 | Spug 容器中的目标位置 | 用途 |
| --- | --- | --- |
| `state/smallapp-simple-settings.json` | `/var/lib/intruoyi-spug/smallapp-simple-settings.json` | NAS 地址、三服显示选项、测试服双模式、进度和恢复路由 |
| `state/smallapp-entry-settings.json` | `/var/lib/intruoyi-spug/smallapp-entry-settings.json` | 应用登记、任务 ID、来源与允许目标 |
| `private/` 下全部文件 | `/run/intruoyi-spug/` 对应的本机私密挂载目录 | 执行桥连接及对应认证头 |

仓库同时提供两份无凭据的 `state/` JSON 供审阅。完整包共 13 个文件，含 5 个连接配置和 5 个认证文件。文件摘要、端口及引用清单见 manifest。

安装前保存接收电脑现有配置，逐项比较后合并到其实际目录；不要直接覆盖整个持久卷、已有应用登记或私密目录。此快照限定测试服：服务器下拉保留三个显示选项，但没有为其他服务器提供可执行绑定。

`tasks` 是原 Spug 数据库中的任务 ID，不能假定另一台电脑相同。必须核对接收端真实任务的 ID、命令及权限，按 `smallapp_entry.py` 的契约更新这三个 ID。历史操作 ID 只作原记录引用，接收端没有原历史时不得伪造历史或复制完成状态。

## 本机转发与远端前提

所有 HTTP 执行桥和 SSH 进度连接都依赖接收电脑自己的转发。原电脑上的转发进程不会随 Git 或配置迁移。以下均连接测试服，不是原来的 18183：

| 本机端口 | 远端 `172.30.30.58` 端口 | 作用 |
| --- | --- | --- |
| 19158 | 19158 | 当前安全模式来源 |
| 19258 | 19258 | 安全模式登记的恢复目标 |
| 19458 | 19458 | 快速模式来源 |
| 20638 | 20638 | 快速模式登记的恢复目标 |
| 21758 | 21758 | 快速模式覆盖恢复目标 |
| 18558 | 22 | Spug 进度查询 SSH |

HTTP 配置使用 `host.docker.internal`，需要从 Spug 容器实际可达的本机监听地址；仅监听接收电脑 `127.0.0.1` 不证明容器可以访问。按接收电脑已有 SSH 凭据及网络规则建立转发，不提供默认凭据，也不复制原电脑的 SSH 私钥。所有请求仍需桥认证，不得关闭认证或绕过实时 `/selections`。

远端对应的控制器、引擎、来源小程序、NAS 挂载及目标身份登记必须实际存在。本包不包含远端文件系统、NAS 密码、Spug 数据库密码或小程序业务登录账号，也没有重新安装远端服务。缺项需要从其实际运维配置获取，不能凭空生成 UUID、占用状态或身份核验结果。

快照的安全来源为 `smallapp-58-tenants-20261023`，快速来源为 `smallapp-58-normal-fast-20261023`，两者是独立登记，不能假定是同一数据库。安全来源名称里的 tenants 指演练小程序自身，不表示授权操作 IntRuoyi 租户。

历史快速业务入口 `http://127.0.0.1:40058/` 是原电脑上的入口，不是远端业务端口的证明。接收端需从对应远端小程序实际监听及控制器登记确定业务入口，再建立自己的转发；不要把该历史 URL 当成已验证的当前入口。

## 恢复前必须核对

从真实页面确认来源在实时 `/selections` 中可用，核对实际容器、数据库身份及目标占用。快照中的空目标可能已被原电脑演练使用；不得清空占用来冒充新目标。仅快速来源登记了覆盖目标，安全来源没有覆盖映射，不能补造一个默认覆盖目标。

只有接收电脑的配置、运行脚本、转发和来源/目标核对均通过后，才通过 Playwright 提交备份恢复。配置成功解密不等于安装成功、来源就绪或业务验收通过。已有 7 项测试失败的边界仍见 `doc/tasks/20261023-spug-everyday-restore/remote-integration.md`。
